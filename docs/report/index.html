11问题诊断

问题 1：细节再现存在方向性差异

检测证据：经标准化校正后，水平/垂直方向的细节再现差异约为 25.0%

可能原因：

  1. 印刷过程中的方向性再现特征
  2. 墨点扩散
  3. 介质传输稳定性

建议验证：

  1. 对多个 ROI 进行方向性复测
  2. 旋转测试卡后重新测量
  3. 对比不同批次样品

问题 2：高频细节响应存在波动

检测证据：经 OECF 与 MTF 标准化校正后，部分高频区域仍存在响应波动，高频响应峰值记录为 7.689
